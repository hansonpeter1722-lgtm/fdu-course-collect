ABOUT THIS INDEX

让资料更容易找到。

由同学整理的课程资料入口。本站与复旦大学官方无隶属或背书关系。

数据从哪里来

页面在构建时读取仓库中已有的七份 CSV：courses、course_repos、collections、collection_files、course_exams、schedule_course_mapping_2026 和 course_mapping_2026。本站不重新抓取资料，不在浏览器中请求 GitHub API。

目前索引 151 门课程、1,207 个课程仓库记录、3,399 条网络试题、14,768 条合集文件，以及 2,040 门 2026 本科开课课程。

数量与课程状态的口径

所有数量从 CSV 实际数据行计算，不计表头和空行。课程仓库按「课程 ID + 仓库全名」去重；同一仓库关联不同课程时分别计数。本次去除 0 条重复关联记录。合集文件数量按 CSV 行数统计，不把 file_count 相加。试题总量包含 2,365 条原表标为「课程表外」的记录，这些记录保留在总索引，不生成课程页。

课程状态采用 courses.csv，并核对 course_mapping_2026.csv：开课、合并、今年未开课、研究生已过滤。「今年未开课」仅表示 2026 年映射状态，不代表资料不可参考；课程开设及调整以学校发布的信息为准。

课程页只设试题、课程资料、代码仓库三个模块。GitHub 仓库与合集文件会放入对应模块；每页最多展示 30 条。网络试题默认仅显示 free 和 preview，paid 与 unknown 保留为明确标注的索引。
